How is my key protected?

The cards are written by Claude, using your key.

  • Your key never reaches this website's server. Your browser sends it straight to Anthropic (api.anthropic.com), the company that makes Claude, and nowhere else.
  • Your key isn't saved. The page only holds it while this tab is open, so closing or reloading the tab erases it.
  • The browser enforces this. The page's security rules block it from sending data anywhere except this site and Anthropic, and from running any code but its own.
  • You can check. Open your browser's developer tools (Network tab) while making a deck: the key appears only in requests to api.anthropic.com.

If you want to be extra safe, make a new key just for this site, set a spending limit in the Anthropic console, and delete the key when you're done.
